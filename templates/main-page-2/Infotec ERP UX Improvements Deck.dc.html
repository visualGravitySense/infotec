Стена текста

«Для чего / для кого / почему» — три абзаца до первого действия

Форма из 4 полей

Имя, email, телефон, сообщение — единственный путь к контакту

Один CTA внизу

Ни одного призыва к действию до самого подвала страницы

Модель 1 · BJ Fogg Behavior Model

Поведение = Мотивация × Способность × Триггер

Мотивация

KPI-лента и реальные цифры сразу под hero вместо абстрактных обещаний

Способность

Одно поле email вместо формы из четырёх — 20 секунд на действие

Триггер

CTA-баннеры на пике интереса вместо одного призыва в подвале

Модель 2 · CREATE Action Funnel

Каждый CTA-блок стал самодостаточной точкой конверсии

Раньше промежуточные призывы вели к форме наверху страницы — пользователь терял намерение, пока скроллил обратно.

Cue → заметная плашка Evaluation → «что будет дальше» Ability → своё поле email в каждом блоке Execution → мгновенное подтверждение
Модель 3 · Spectrum of Thinking Interventions

Не каждое решение заслуживает нажатия одной кнопки

Быстрое действие

Скачать спецификацию модуля — один клик, автоматический нудж

Взвешенное решение

Таблица «до/после» + расчёт экономии для решения на годы вперёд

Модель 4 · Dual Process Theory

Система 1 получает дефолт, Система 2 — данные по запросу

Система 1 · быстрая

Модуль «Продажи» открыт по умолчанию с меткой «★ выбор большинства клиентов»

Система 2 · аналитическая

Раскрывающийся расчёт «как считается экономия -40%» — скрыт, доступен по клику

Модель 5 · Nudge Theory

Подталкиваем к выбору, не ограничивая свободу

Якорь: «11–50 человек» помечен как «★ чаще всего» среди размеров компании

Фрейминг потерь: «данные разрознены — компания теряет часы и маржу»

Снижение риска: «без спама, отписаться можно в любом письме»

Модель 6 · Behavioral Economics

Учитываем эффект владения и страх смены системы

Эффект владения

«Ваша подборка: Продажи, Закупки» — просмотренные модули превращаются в собственный список

Status quo bias

«Без остановки текущей работы» снимает страх издержек перехода

Модель 7 · Persuasive Technology

Настоящий прогресс, а не фальшивые счётчики

Изучил модуль → сравнил → отправил заявку

Плавающая кнопка меняет текст по факту действий: «Спецификация по 3 модулям →» вместо статичного призыва — и «Шаг 3 из 3 завершён» после отправки

Модель 8 · Behavior Design

Ни один раздел не остался без точки действия

Модули → спецификация

Отрасли → «спросить об адаптации»

ИИ-агенты → показать на своих данных

Отзыв → забронировать звонок

Модель 9 · BJ Fogg Behavior Grid

Три ступени вместо одного большого решения

DOT · разово

Спецификация модуля в один клик

SPAN · 14 дней

Демо-доступ без обязательств продлевать

PATH · навсегда

Полное внедрение с окупаемостью за 2–3 месяца

Модель 10 · Support Conscious Action

Для решения на годы вперёд — время подумать, а не кнопка

Пришлите себе на почту

Сравнение можно обсудить с командой вместо решения в моменте

Чек-лист перед звонком

Данные для переноса, ответственный, 2–3 месяца на переход — и явное «решать сегодня не обязательно»
